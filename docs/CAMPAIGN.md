# 五地战役与怪物

五个目的地共 147 关，全关卡可自由选择。每关 1–3 波；每第 5 关为小首领关，地区末关为原指定大首领。普通关准备 18 秒，最终关准备 22 秒。所有场地为 6 行 × 10 列。原始普通怪物移动速度统一降低 25%。

## 数据接口

`getStages(mapId)` 返回该地图关卡数组；`getStage(stageId)` 或 `getStage(mapId, stageIdOrNumber = 1)` 返回单关。找不到时返回 `null`。

`id` 稳定采用 `herta-01` 格式。`waves` 为波数，`waveEnemyCounts` 为每波敌人数，`enemyCount` 为总数。`modifier` 为 `random-transform` 或 `null`；`miniBoss` / `boss` 为敌人 ID 或 `null`。`areaId` / `areaName` 与 `tint` / `decoration` 控制分区表现。胜利记录和自由选关由界面管理，不改变只读战役数据。
