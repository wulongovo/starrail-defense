# 战役与联动模拟规则

这些数值与操作方式都是本项目的塔防改编，不是《崩坏：星穹铁道》原作技能的完整复刻。

## 关卡与棋盘

`new GameEngine({ map, stage, mode, seed, onEvent })` 接受地图内的关卡序号或完整 ID（如 `herta-23`），默认第一关。完整 ID 决定地图。引擎不限制选关，通关记录由界面保存。

所有地图为 6 行 10 列，共 60 格。实体坐标仍是格子中心（列 0–9，行 0–5）；普通敌人从右侧 `cols + 0.25…0.60` 进入，首领停留在 `cols - 0.2`。召唤、弹道、随机空位和离场边界均跟随列数。

147 关包含黑塔空间站 23、仙舟 29、匹诺康尼 32、翁法罗斯 36、二相乐园 27 关，每关 1–3 波，每 5 关有一个普通怪物精英，区域最后一关有对应大首领。非终关准备 18 秒、终关 22 秒，单个敌人间隔 4.5–5.8 秒。待出场队列和当前敌军全部处理后，间隔 10 秒才开始下一波。

黑塔第 7、13、19 关开启随机变身；其他区域的随机关由 `campaign.js` 指定。每次部署只支付原卡费用和冷却，然后从可用角色池中选择一个角色，占用同一个格子；迷迷不进入随机卡池。失败部署不消耗随机数、费用或冷却。

全部卡牌冷却为各自基准减 1 秒，最低 0.5 秒；费用为基准的 85%，四舍五入到 5 的倍数（非零最低 10）。迷迷仍是零费召唤物，不能直接部署。开拓者各命途共享开拓者冷却。

## 三组手动联动

`getLinkStates()` 返回各组 `id,name,members,actors,actorIds,charge,required,available,ready`。`actors` 是角色类型 ID，`actorIds` 是战场实例 ID。`releaseLink(id)` 返回 `{ ok, reason? }`，只有战斗中、成员同时存活、充能达到 5 时可释放。

每一次实际命中攻击动作计 1 次，两个成员共同累计 5 次。穿透击中三人、范围攻击击中多人、神君追加伤害都不会把同一次攻击重复计数。没有敌人、射空或施放纯支援不计数；蓄满后不自动释放，也不能继续储存多轮。重复部署同种角色时，只有最早在场的存活实例作为该组成员；伙伴阵亡、撤回或变成其他角色时清空该组充能，补上新实例后重新开始。

| ID | 成员 | 手动释放效果 |
| --- | --- | --- |
| `dragon_thunder` | 丹恒·饮月、景元 | 对全场敌人造成 360 基础伤害。 |
| `earthbound_oath` | 丹恒·腾荒、丹恒 | 对全场敌人造成 120 基础伤害，并为存活友军增加 300 护盾。 |
| `foxflame_meteor` | 忘归人、流萤 | 对全场敌人施加 8 秒易伤、5 秒 50% 减速，并造成 200 基础伤害；该次伤害会受到易伤增幅。 |

联动通过 `link-charge`、`link-ready`、`link` 发出日志。`link` 的事件和特效均含 `linkId,name,actors,actorIds,duration:2.5`，特效另含 `x,row,color,ttl,maxTtl`。重复角色不影响画面上两位主角的识别。

## 花火连续变身

花火每两次实际命中攻击后变成一个不同于当前类型的可用角色。变身保留实例 ID、格子、当前生命比例、已有护盾和 `shapeshifter` 标记；重置本轮两击计数，累计 `transformCount`。第一次部署后不额外付费。`shapeshift` 事件含 `unitId,fromType,character,transformCount`，渲染器据此替换真实素材。

生产、治疗、护盾、纯支援或召唤类外观改用虚影普攻，使任何变身都能通过下一轮两击继续变化。它们不会借召唤外观无限生成单位。变身前已经射出的旧弹道不计入新外观的两击周期。随机结果与关卡随机变身均由同一个种子生成器控制。

## 怪物技能与应对

普通关卡只从 16 种真实怪物的配置池抽取。盲盒与欢愉召唤的角色池覆盖全部 92 张可用卡，有 26% 概率改从 16 种怪物中选出一个已被策反的友军。旧角色敌方投影仅保留为兼容定义。所有普通怪物的基础移动速度乘以 0.75；被策反的怪物保留自身技能与友方阵营。

| 行为 | 已实现的实际作用 | 应对方式 |
| --- | --- | --- |
| 近战 | 前进并攻击同路阻挡者。 | 盾墙、减速、嘲讽、火力。 |
| 远程 | 射程内停止前进，发射能被前方伙伴拦截的弹道；策反后向右射击。 | 护盾吸收、存护主角近处嘲讽拉近、策反。 |
| 护盾 | 周期性为同阵营近处单位补盾，单次技能上限为基准护盾的两倍。 | 优先击破支援怪物，集中火力破盾。 |
| 再生 / 治疗 | 回复自身或同阵营范围内存活单位的实际生命，不能复活。 | 集火、易伤、策反治疗者。 |
| 冲锋 | 0.8 秒预警后加速 3 秒。 | 减速仍生效，正面的防守角色仍能阻挡。 |
| 飞跃 | 0.8 秒预警后前跃 2.3 格。 | 有护盾的伙伴、杰帕德、砂金、存护主角或腾荒会拦截。 |
| 自爆 | 靠近后 1.5 秒读条，爆炸伤害邻近范围并自身退场。 | 读条期间击破会取消爆炸。 |
| 召唤 | 按各自间隔生成援军，每个召唤者最多同时存活 3 名子单位。 | 优先击破召唤者；子单位不能递归召唤。 |

怪物预警对象位于 `enemy.behaviorState`，包含 `key,skillName,castRemaining,castDuration`。预警特效提供 `type:'warning',radius,enemyId,ttl,text`；日志事件为 `monster-cast`、`monster-skill`、`monster-shot` 和 `monster-summon`。

## 验证范围

2026-09-28 的 `npm test` 共 88 项通过。15 个固定种子的正常资源实战涵盖每个区域的初关、中关、终关，全部在 420 秒上限内胜利；终关实际耗时 167.50–198.45 秒。机器结果在 `boss-validation.json`，单元与集成回归位于 `tests/engine.test.mjs`、`tests/expansion.test.mjs`。

这些结果验证模拟逻辑和一套可行部署策略，不代表每个随机种子或所有阵容都已经穷举，也不能替代浏览器中的模型、动画、移动端界面验收。
