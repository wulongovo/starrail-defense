# 星穹防线 v0.4

> **GitHub 仓库仅包含源码，不包含模型、角色图片或完整离线游戏包。** 下述 3D 覆盖和画面验证记录对应开发者本机的完整素材版本。直接克隆仓库不会获得这些素材；需自行取得可用于相应用途的资源，按 [本地素材接入说明](docs/LOCAL_ASSETS.md) 放入后构建。仓库不会自动安装、下载或发布第三方模型。

《崩坏：星穹铁道》同人塔防：92 张可部署角色卡、五个区域共 147 关，全部使用 6 行 × 10 列战场。星琼代替阳光，普通敌军为 16 种崩铁怪物，具有远射、护盾、再生、治疗、冲锋、飞跃、自爆和召唤等行为。每关 1–3 波，每五关小首领，区域末关为独立地区首领。剧情、台词、数值和塔防技能均为同人改编。

92 张角色卡的场上单位均已接入 3D，使用 90 份角色 PMX；存护、同谐开拓者共用基础开拓者人物。迷迷、萨姆、武器、帕姆、16 种普通怪物、3 种召唤物和五个地区首领也使用实际模型。素材来自官方活动 CDN 与公开社区存档，逐项来源和哈希见 [角色 3D 覆盖清单](docs/model-coverage.json)、[怪物 3D 覆盖清单](docs/enemy-model-coverage.json)。社区怪物资源为原 FBX 转 GLB，保留原几何、UV 和骨骼，并非官方 MMD 配布。

行走改为按实际位移驱动双腿，加入脚步 IK、摆臂、重心转移、转向与起停过渡；站立时不会原地走路，暂停会冻结动作。动作由本游戏编写，并非原游戏动作文件。记忆主角和召唤的迷迷使用独立模型，迷迷保持较小体型。欢愉主角的镜像包沿用主角基础服饰，不能理解为新服装模型。

## 本地离线游玩

运行 `npm run package` 后，解压 `release/星穹防线-0.4.0-local-preview.zip`，使用近期桌面版 Edge / Chrome 打开 `星穹防线.html`。不需要 Node.js、账号或本地服务器；浏览器需支持 WebGL 和 DecompressionStream。ZIP 包含完整游戏、中文说明、模型接入清单和来源说明。

`dist/星穹防线.html` 是完整单文件游戏。构建会把 Three.js、游戏代码、样式、模型和贴图全部内嵌，不使用 CDN；模型经过 gzip 压缩，首次用到时才解压，原 PMX 字节保持不变。第一次载入与解析模型需要一些时间。后续游玩无需联网。

本归档供本地预览。所用模型的原始规约包含“请勿二次配布”“请勿用于商业用途”，因此当前含模型的 HTML、ZIP 和后续 EXE 不能当作可自由分享的发行包。对外提供游戏需要取得素材授权或替换为允许分发的素材。技术打包能力与素材分发许可是两件事，详见 [模型来源与使用边界](docs/official-model-research.md)。若 `release` 中仍有旧的 `*-offline.zip`，它是早期程序小人版本，已过期，不代表现在的游戏。

## 开发和验证

在本目录运行以下命令，需要 Node.js 20 或更新版本：

```powershell
npm install
npm run dev
```

浏览器打开 `http://127.0.0.1:4178`。`dev` 会先构建，再启动仅监听本机的静态服务；修改代码后重新运行即可更新，不包含热更新。

```powershell
npm test
npm run build
npm run package
```

`npm test` 检查游戏模拟和模型导入；`build` 生成 `dist/index.html` 和中文单文件；`package` 重新构建并生成本地离线预览 ZIP。Windows 打包优先使用系统 PowerShell 的 `Compress-Archive`，压缩模块不可用时使用 Python 3 标准库；其他平台使用 Python 3。测试通过不等于所有视觉效果与设备兼容性均已验证。

浏览器回归为 `node tests/browser-smoke.mjs`、`node tests/boss-browser.mjs` 和 `node tests/expansion-browser.mjs`。运行前需要最新构建、开发服务与可用 Playwright/Chromium；可通过 `GAME_URL`、`PLAYWRIGHT_MODULE`、`PLAYWRIGHT_CHROMIUM` 指定环境。真实正常资源实战记录见 [引擎验收结果](docs/boss-validation.json)，浏览器截图与报告在 `tests/evidence`。

本次模型逐卡检查为 `node tests/model-roster-browser.mjs`，动作录帧为 `node tests/locomotion-browser.mjs`。这些是原模型的浏览器陈列、合成行走轨迹核验，不能当作正常通关记录或官方动画。

怪物完整陈列检查为 `node tests/monster-roster-browser.mjs`；帕姆、朝向和攻击特效检查为 `node tests/facing-pompom-browser.mjs`。`node scripts/validate-campaign.mjs` 可重新生成新版 15 个首关、中段关、终关的正常资源模拟记录。

## 操作

- 点击角色卡，再点击空格部署；数字键 `1`–`9` 选择前九张卡。
- 「伙伴库」可搜索、翻页选择 92 张卡，选中的新卡加入快捷栏；「怪物档案」可查看怪物行为与首领机制。
- `Esc` 或鼠标右键取消部署，空格键暂停/继续。
- 点击星琼收集；掉落 8 秒后自动收集。
- 使用速度按钮切换 1× / 2× / 3×。盲盒模式中部署「奇遇盲盒」开出随机角色，也可使用基础伙伴卡。
- 点击「撤回角色」后点击已部署伙伴可移除；选择开拓者卡后，在右侧档案切换命途再部署。
- 在黑塔空间站、仙舟「罗浮」、匹诺康尼、翁法罗斯、二相乐园中选择战场。五个地区对应末日兽、幻胧、神主日、来古士、归寂首领战；观察蓄力提示，使用战术按钮应对。
- 「选择关卡」自由进入各区关卡，通关记录保存在当前浏览器。五个区域依次为 23、29、32、36、27 关。黑塔第 7、13、19 关每次部署后随机变身，仍扣原卡费用。
- 饮月＋景元、腾荒＋丹恒、忘归人＋流萤的两位成员同时在场，共同真实攻击 5 次后，点击「释放连携」。蓄满不会自动释放，伙伴离场后重新蓄力。
- 花火每两次命中攻击变成另一名角色，保留变身规则、血量比例、护盾与格子；非攻击外观会使用虚影普攻继续积累。

所有部署卡冷却在基准上减少 1 秒（最低 0.5 秒）；费用按基准 × 0.85，四舍五入至 5 的倍数。例如知更鸟 45、三月七 85、盲盒 105 星琼。首领的屏障 75、净化 50 星琼属于独立支援操作。准备阶段为 18 秒，终关为 22 秒；出怪间隔约 4–6 秒，清空当前波后休息 10 秒再迎接下一波。

v0.4 全部关卡开局为 200 星琼。天空每 7 秒掉落、知更鸟每 8 秒产出、同谐主角每 10 秒产出，翁法罗斯圣火奖励每 18 秒结算。普通怪物生命提高 35%，地区首领提高 20%；每波数量按原数量 × 1.5 向上取整，仍为 1–3 波。卡芙卡保留雷击普攻，每 5 秒策反同路前方最近的非 Boss 怪物，召唤物也有效，小 Boss 和地区 Boss 免疫；没有可用目标时保留就绪状态。

每路左侧有一只独立 3D 帕姆，敌人逼近防线时自动出动，每关一次，清扫同路敌军；首领受到 1800 点基础冲撞伤害（受防御减伤），友军不受伤。帕姆不占用部署格。角色面向右、敌军面向左，怪物策反后朝右。攻击动作改为蓄力、打击、收势一个周期，增加挥击弧、弹道拖尾、命中和护盾闪光、言灵连线。

详细角色表见 [角色设计](docs/CHARACTERS.md)，联动、变身和怪物实现规则见 [v0.2 机制说明](docs/expansion-mechanics.md)，当前数值以伙伴库和 `src/data.js` 为准。原版角色网格、材质和骨骼已导入，但本作动画不是原游戏动作；PMX 刚体、完整物理与全部 IK 效果也不等于原始 MMD 环境。场景是为塔防重新制作的战场，不是提取的原游戏地图。

## 可选：Windows 独立程序

离线 HTML 和本地预览 ZIP 是当前交付方式，尚未生成或验证 Windows EXE。仓库提供 Electron 入口，可在联网开发机安装以下可选依赖后构建 portable EXE：

```powershell
npm install --save-dev electron electron-builder
npm run build
npm run desktop
npm run dist:win
```

Electron 只加载本地构建，关闭 Node.js 页面访问并启用上下文隔离。首次安装与打包需要下载工具。素材规约同样适用于包含这些素材的 EXE。
